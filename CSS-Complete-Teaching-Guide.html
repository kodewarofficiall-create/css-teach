What is CSS?

Cascading Style Sheets - the paint of every website

CSS is the stylesheet language that controls how HTML elements look - their colors, fonts, spacing, sizes, position and animations. HTML says what something is, CSS decides how it looks.

💡 In simple words

If HTML is the bricks and rooms of a house, CSS is the paint, lighting and furniture. The house works without paint, but nobody wants to live in it! You write CSS as small rules: a selector picks the element (like "every paragraph"), and the rules inside the braces say what to change (like "make the text blue").

📖 New words in this lesson
  • stylesheet - a file full of style rules (a .css file) that the HTML page loads.
  • rule - one complete instruction: a selector + braces + declarations.
  • selector - the part before the braces; it chooses which elements get styled.
  • property - what you want to change, such as color or font-size.
  • value - the new setting for that property, such as red or 20px.
  • declaration - one property: value; pair.
🧱 HTML

Structure - headings, text, images, links. The content skeleton.

🎨 CSS

Presentation - colors, fonts, spacing, layout, animation.

⚡ JavaScript

Behaviour - what happens when the user clicks, types or scrolls.

💡
Why "Cascading"? Later rules and more specific rules override earlier ones - like water cascading down a waterfall, the most specific style wins. You will see this in Lesson 3 and in the box model lessons.

CSS Syntax & Comments

How every CSS rule is built

Every instruction in CSS is written as a rule: the selector says which elements, the declarations say what to change about them.

💡 In simple words

A rule looks like selector { property: value; }. The curly braces hold the declarations, each declaration is property colon value semicolon. Put several declarations for one element inside the same braces, one per line.

Part Example What it is
selector h2, .card, a:hover Picks the element(s) the rule applies to
declaration block { color: red; } The curly braces and everything inside them
property color: The feature you want to change (left of the colon)
value #333; The setting given to that property (right of the colon)
declaration color: #333; One property + value pair, ended with a semicolon
comment /* for humans only */ Completely ignored by the browser
rule set p { color: blue; font-size: 16px; } A selector plus its declaration block = one complete rule
At-rule Example Simple explanation
@media @media (max-width: 768px) { ... } Changes the design based on screen size. Used to make websites responsive on mobiles, tablets, and desktops.
@import @import url("theme.css"); Loads another CSS file into your stylesheet.
@font-face @font-face { font-family: "MyFont"; src: url("font.woff2"); } Lets you use a custom font file on your website.
@keyframes @keyframes slide { from { opacity: 0; } to { opacity: 1; } } Defines the steps of an animation, such as fading in or moving an element.
@supports @supports (display: grid) { ... } Applies CSS only when the browser supports a particular feature.

Ways to Apply CSS

Inline, internal and external stylesheets

There are three places to write CSS. Learning all three helps you read any project - but real websites almost always use the external method.

💡 In simple words

Inline = writing the style right on the tag (quick but messy). Internal = a <style> block inside the page head (handy for one page). External = a separate .css file linked from the page (clean, reusable, professional).

Method Where it is written Best for
Inline Inside the tag: style="color:red" One-off quick fixes & demos
Internal <style> ... </style> in the head Single pages & learning
External A separate styles.css file Every real website ⭐

1. Inline CSS — CSS directly inside an HTML tag

🌐 htmlindex.html
<h2 style="color: red;">Hello World!</h2>
<p style="font-size: 20px;">This is inline CSS.</p>

💡
Explanation: CSS is written inside the <style> tag, usually in the HTML <head> section.
⭐ Best for: Styling a single HTML page.

3. External CSS — CSS in a separate file

Create two files in the same folder: index.html (the HTML structure) and style.css (the CSS styling).

👁 you see a green "Hello World!" heading and a light-yellow padded paragraph - all pulled in from style.css

Hello World!

This is external CSS.

💡
Explanation: the <link> tag connects the HTML file to the separate CSS file.
⭐ Best for: Real websites with multiple pages.
⚡
Rule of thumb: use external stylesheets. One CSS file can style every page of your site - change the color once, and 100 pages update together.
⚠️
Which one wins if they conflict? Specificity decides: inline beats internal beats external for the same element. That is why inline styles should be avoided - they are hard to override later.
⚠️
"My CSS does nothing" - the 6-check checklist: (1) is the file linked correctly and the path right? (2) any typo in the selector - .btn and btn are different things? (3) missing } breaks everything after it? (4) a missing colon or semicolon makes that one declaration invalid - check the dev tools (F12) for red lines? (5) is another more specific rule overriding yours? (6) is your browser cache holding the old file (Ctrl+F5 to force reload)?

Selectors

How CSS picks the elements you want to style

A selector is the target-finder of CSS. It tells the browser exactly which elements a rule should apply to - all paragraphs, only the element with a certain class, or just one unique id.

💡 In simple words

Think of selectors as mail labels. A type selector mails every house on the street (all <p> tags). A class selector mails everyone wearing the same badge (.card). An id selector mails one specific person (#main).

Selector Syntax What it selects
Element p { } All <p> elements
Class .card { } All elements with class="card" (most used ⭐)
ID #header { } The element with id="header"
Universal * { } Every element
Grouping h1, h2 { } All <h1> and <h2> elements
Descendant .nav a { } All <a> elements inside .nav
Child .nav > a { } Only <a> elements directly inside .nav
Attribute input[type="email"] { } Email input elements
Adjacent sibling h2 + p { } The first <p> immediately after an <h2>
General sibling h2 ~ p { } All <p> siblings that appear after an <h2>

Colors & Backgrounds

Painting text and boxes with CSS

CSS accepts colors in many formats: by name, hex, rgb, hsl, and newer spaces like hwb/oklch. The same formats work for color (text), background-color, border and almost any property that needs a color.

💡 In simple words

Pick your paint however you like: by name (red), by hex code (#ff6600), by red-green-blue mix (rgb(255,102,0)) or by hue-saturation-lightness (hsl(24,100%,50%)). Add a 4th a channel (like rgba(0,0,0,0.5)) and your paint becomes see-through.

Format Example Notes
Named tomato Easy-to-use built-in color names.
HEX #ff6347 Popular format using #RRGGBB.
RGB rgb(255, 99, 71) Red, green, and blue values range from 0–255.
RGBA rgba(255, 99, 71, 0.5) Adds transparency using an alpha value from 0–1.
HSL hsl(9, 100%, 64%) Uses hue, saturation, and lightness.
Linear Gradient linear-gradient(to right, red, blue) Blends two or more colors to create a gradient background.

Units & Sizing

px, %, rem, vw, vh and the clamp() superpower

Sizes in CSS come in two families: absolute (fixed, like pixels) and relative (they react to the screen, parent or font size). Responsive sites lean on relative units.

💡 In simple words

px is a physical dot - always the same size. % is a slice of the parent. rem is a slice of the root font size (1rem ≈ 16px) - the safest choice for text and spacing because it respects the user's browser settings. vw / vh are slices of the viewport (screen width/height) - perfect for full-screen heroes.

Unit Relative to Example Good for
px Fixed size width: 300px; Borders and precise sizing
% Parent element width: 80%; Flexible layouts
rem Root (html) font size font-size: 1.25rem; Text and spacing
em Current element's font size (for padding) padding: 1em; Scalable components
vw / vh Viewport width / height height: 100vh; Screen-sized sections
min() / max() / clamp() Calculated size limits font-size: clamp(1rem, 2.5vw, 2rem); Responsive sizing

The Box Model

Every element is a box: content → padding → border → margin

This is the #1 concept in CSS. Every single element on a page is a rectangular box made of four layers - and the browser draws them from the inside out.

💡 In simple words

Picture a framed photo on a table: the content is the photo, the padding is the white mat around it, the border is the frame, and the margin is the empty table space between it and the next frame. Padding is inside the frame; margin is outside.

Margins & Padding

Spacing outside and inside the border

Two spacing systems: margin creates space outside the border (between boxes), padding creates space inside the border (between the border and the content).

💡 In simple words

Think of a framed photo: padding is the mat board between the photo and the frame, margin is the empty wall around the frame. Padding is always coloured by the background; margins are transparent gaps.

Property Type Example What it does

Height, Width & Min/Max

Controlling element size and the max-width pattern

Width and height set exact sizes; min-*/max-* set the guard rails so boxes can grow or shrink but never cross a limit you choose.

💡 In simple words

max-width is the hero of responsive design: a container with max-width: 1200px; margin: 0 auto; fills the screen on phones and stays a comfortable readable width on huge monitors - one line, no media query.

Property Example What it does
width width: 300px; Sets the width of an element. Can use px, %, vw, or auto.
height height: 200px; Sets the height of an element.
min-width min-width: 320px; Prevents the element from becoming narrower than 320px.
min-height min-height: 100vh; Prevents the element from becoming shorter than the viewport height.
max-width max-width: 1200px; Prevents the element from becoming wider than 1200px.
max-height max-height: 400px; Limits the element's height to 400px.
inline-size / block-size inline-size: 100%; Logical alternatives to width and height that follow writing direction.

Overflow & Float

What happens when content is too big - and the classic float technique

overflow decides what happens when content is bigger than its box. float is the old-school layout tool - rare in modern layouts, but you will meet it in real code and in "wrap text around an image" designs.

💡 In simple words

Overflow is like a drawer: visible stuff just spills onto the floor (default), hidden the drawer lid is forced shut (content cut), scroll sliders are always fitted, auto sliders appear only when needed ⭐. Float is the old trick of pushing a box to the side so text flows around it - like a magazine photo.

Value Behavior Use for
visible Content can extend outside the box. Decorations that extend beyond a box.
hidden Extra content is clipped; no scrollbars are shown. Cropping content.
scroll Provides scrolling, even when not needed. Fixed-size content areas.
auto Scrollbars appear when needed. Sidebars, tables, and previews.
clip Clips content without allowing scrolling. Strict cropping.

Typography - size, weight, spacing, alignment

Typography properties control how letters look: which typeface, how big, how bold, how far apart, and how the lines are aligned and spaced.

💡 In simple words

font-family chooses the typeface (always list several, ending with a generic like sans-serif), font-size sets how big, font-weight how heavy (400 = normal, 700 = bold), line-height how much air between lines (1.5 is comfy), and text-align lines up the text left, center or right.

Display

Block, inline, inline-block, none and flex - how boxes flow

The display property decides how an element participates in the page flow: does it take the full width on its own line, sit inside text like a word, or disappear completely?

💡 In simple words

block = a full-width brick (it starts a new line, height works). inline = a word (flows inside text, width/height ignored). inline-block = a word that also accepts width/height - the useful hybrid. none = removed from the page entirely.

Value New line? Width/height work? Examples
block Yes Yes div, p, h1
inline No No span, a, b
inline-block No Yes badges, buttons in a row
none - - hidden completely (no space left)
flex Yes Yes (as a flex container) nav bars, card rows, toolbars - children arrange on one axis

CSS Backgrounds
Background color, images, repeat, size and gradients
          

        

        
Backgrounds fill the area inside an element (padding box). You can paint it a solid
          color, lay an image behind content, or use a smooth gradient - then control how the image repeats and
          fits.


        

          
💡 In simple words

          
A background is the wallpaper behind your furniture: furniture (content) stays on top, wallpaper
            covers the whole inner wall. By default an image tiles (repeats) to fill any size - so most designs
            either turn repetition off and use background-size: cover, or use a
            gradient instead of an image.

        


        
1. Background properties

        

          

            

              Property
              Example
              What it does
            

            

              background-color
              #eef2ff, red, transparent
              Sets the background color of an element.
            

            

              background-image
              url("bg.jpg"), linear-gradient(red, blue)
              Adds an image or gradient behind the content.
            

            

              background-repeat
              repeat, no-repeat, repeat-x, repeat-y
              Controls whether the background image repeats.
            

            

              background-position
              center, top right, 50% 0
              Sets the starting position of the background image.
            

            

              background-size
              cover, contain, 100% 50%
              Controls the image size. cover fills the area and may crop; contain shows the whole image.
            

            

              background-attachment
              scroll, fixed
              Controls whether the background scrolls with the page or stays fixed.
            

            

              background-origin
              border-box, padding-box, content-box
              Sets the box area used as the starting reference for the background image.
            

            

              background-clip
              border-box, padding-box, content-box
              Controls how far the background extends within the element.
            

            

              background
              #eef2ff url("bg.jpg") no-repeat center / cover
              Shorthand for setting multiple background properties in one declaration.

CSS Shadows
text-shadow and box-shadow - full anatomy
          

        

        
Shadows add depth. text-shadow paints behind letters; box-shadow paints
          around a whole box. Both accept multiple comma-separated shadows.


        

          
💡 In simple words

          
Imagine a lamp shining on your box: offset-x/y move the shadow (the lamp's position),
            blur-radius softens the edges (a cloudy lamp), spread-radius grows or shrinks the shadow's
            size, and color decides how dark it is. Put inset first and the
            light goes inside the box (pressed/engraved look).
          

        


        
1. CSS Shadow Properties

        

          

            

              Property
              Example
              What it does
            

            

              box-shadow
              box-shadow: 0 4px 12px #0003;
              Adds a shadow around an element.
            

            

              text-shadow
              text-shadow: 2px 2px 4px #0008;
              Adds a shadow behind text.
            

          

        


        
2. Important box-shadow values

        

          

            

              Value
              Example
              What it does
            

            

              offset-x
              4px
              Moves the shadow right; negative values move it left.
            

            

              offset-y
              6px
              Moves the shadow down; negative values move it up.
            

            

              blur-radius
              10px
              Makes the shadow softer.
            

            

              spread-radius
              2px
              Expands or shrinks the shadow.
            

            

              color
              rgba(0, 0, 0, 0.2)
              Sets the shadow color and transparency.
            

            

              inset
              inset 0 2px 5px #0003
              Places the shadow inside the element.
            

            

              none
              box-shadow: none;
              Removes the shadow.
            

          

        


        
📝
          
Remember: box-shadow is for the element's box -
            text-shadow is for the text itself. Multiple shadows can be separated by
            commas.

CSS Links
Link states, underline control, link buttons
          

        

        
Links have four states - unvisited, visited, hover and being-clicked. CSS lets you style each
          one, remove the underline, or turn a link into a full button.


        

          
💡 In simple words

          
Think of a link as a road sign with four moods: fresh (never seen), familiar (already
            visited), approaching (mouse over it), pressed (click in progress). Give each mood its own
            rule with :link, :visited,
            :hover, :active - and always list them in
            that order (the handy memory word LV-HA).
          

        


        
1. Link properties and pseudo-classes

        

          

            

              Property / Pseudo-class
              Example
              What it does
            

            

              :link
              a:link
              Styles an unvisited link.
            

            

              :visited
              a:visited
              Styles a visited link.
            

            

              :hover
              a:hover
              Styles a link when the pointer is over it.
            

            

              :active
              a:active
              Styles a link while it is being activated.
            

            

              text-decoration
              text-decoration: none;
              Removes or changes the underline.
            

            

              color
              color: blue;
              Changes the link's text color.
            

            

              display: inline-block
              display: inline-block;
              Lets a link behave like an inline button.
            

            

              display: block
              display: block;
              Makes the link fill its available row width.
            

            

              transition
              transition: color 0.2s ease;
              Smooths changes such as link color.
            

          

        


        
📝
          
Remember the order: :link →
            :visited → :hover →
            :active (LVHA).

Styling Forms
Inputs, labels, states, focus, validation styles
          

        

        
Forms are where design meets usability. CSS makes controls comfortable to use - clear labels,
          big enough targets, obvious focus - but remember: CSS styles forms, it does not validate them

Transforms & Filters
translate, rotate, scale, skew - and visual
              filters
          

        

        
transform moves, spins, grows or skews an element without affecting the layout
            around it (neighbours never shift). filter applies camera-like effects such as blur and
          brightness.


        

          
💡 In simple words

          
Transform is a photo edit: the picture slides (translate), turns
            (rotate), zooms (scale) or leans
            (skew) - but the photo frame on the wall (the layout) never changes.
            Filter is the camera lens: blur, brightness, grayscale - purely visual.

        


        
1. CSS Transform & Filter Properties

        

          

            

              Property / Function
              Example
              What it does
            

            

              transform: translate()
              translate(20px, -10px)
              Moves an element right and up.
            

            

              transform: rotate()
              rotate(45deg)
              Rotates an element clockwise.
            

            

              transform: scale()
              scale(1.2)
              Enlarges an element by 20%.
            

            

              transform: scaleX()
              scaleX(0.5)
              Makes an element half as wide.
            

            

              transform: skew()
              skew(10deg)
              Slants an element.
            

            

              transform-origin
              left top
              Changes the point around which an element transforms.
            

            

              filter: blur()
              blur(4px)
              Blurs an element.
            

            

              filter: brightness()
              brightness(120%)
              Makes an element brighter.
            

            

              filter: grayscale()
              grayscale(100%)
              Removes its colors.
            

            

              filter: saturate()
              saturate(150%)
              Increases color intensity.
            

            

              filter: contrast()
              contrast(120%)
              Increases contrast.
            

            

              filter: drop-shadow()
              drop-shadow(4px 4px 4px #0005)
              Adds a shadow following the visible shape.
            

          

        


        
📌
          
Important: transform changes how an element looks without changing its normal layout
            space. Filters apply visual effects. You can combine multiple filter functions in one declaration.

CSS Animations
Movement and life with @keyframes - in pure CSS
          

        

        
Animation plays a scripted sequence with @keyframes - it runs by itself,
          no JavaScript and no hovering needed.


        

          
💡 In simple words

          
An animation is a movie: you record the scenes in
            @keyframes (0% → 100%) and press play with
            animation. You control how long it plays, how fast, how many times, and
            in which direction.
          

        


        
⚠️
          
Kindness first: respect users who dislike motion with
            @media (prefers-reduced-motion: reduce) { * { animation: none; } } -
            and keep durations short (0.2-0.4s) so the UI never feels sluggish.
          

        


        
1. Animation properties

        
Animations use @keyframes to define the stages of an effect.

        

          

            

              Property
              Values
              Example
              Meaning
            

            

              animation-name
              none, a keyframes name such as fade, bounce,
                slide
              animation-name: fade;
              Selects the animation to play.
            

            

              animation-duration
              0s, 0.5s, 1s, 2s, 500ms
              animation-duration: 2s;
              Sets the duration of one cycle.
            

            

              animation-timing-function
              ease, linear, ease-in, ease-out,
                ease-in-out, steps(), cubic-bezier()
              animation-timing-function: linear;
              Controls the animation's speed.
            

            

              animation-delay
              0s, 0.5s, 2s, -1s
              animation-delay: 1s;
              Delays the animation; a negative value starts partway through its timeline.
            

            

              animation-iteration-count
              1, 2, 3, infinite
              animation-iteration-count: infinite;
              Sets how many times it plays.
            

            

              animation-direction
              normal, reverse, alternate,
                alternate-reverse
              animation-direction: alternate;
              Controls the direction of playback.
            

            

              animation-fill-mode
              none, forwards, backwards, both
              animation-fill-mode: forwards;
              Controls styles before and after playback.
            

            

              animation-play-state
              running, paused
              animation-play-state: paused;
              Plays or pauses an animation.
            

            

              animation
              Name, duration, timing, delay, count, direction, fill mode, play state
              animation: fade 2s ease 0s infinite alternate;
              Combines animation settings into one line.
            

          

        


        
2. Animation direction values

        

          

            

              Value
              Meaning
            

            

              normal
              Plays forward each cycle.
            

            

              reverse
              Plays backward each cycle.
            

            

              alternate
              Plays forward, then backward, repeatedly.
            

            

              alternate-reverse
              Plays backward first, then forward.
            

          

        


        
3. Animation fill-mode values

        

          

            

              Value
              Meaning
            

            

              none
              Does not retain animation styles outside playback.
            

            

              forwards
              Retains the final keyframe's styles after playback.
            

            

              backwards
              Applies the starting keyframe's styles during the delay.
            

            

              both
              Applies both the backwards and forwards behavior.
            

          

        


        
4. @keyframes values

        
Inside @keyframes, you define the styles at different points in the
          animation.

        

          

            

              Keyframe value
              Meaning
              Example
            

            

              from
              Beginning of the animation (0%).
              from { opacity: 0; }
            

            

              to
              End of the animation (100%).
              to { opacity: 1; }
            

            

              0%
              Beginning
              0% { transform: translateX(0); }
            

            

              50%
              Halfway through
              50% { transform: translateX(50px); }
            

            

              100%
              End
              100% { transform: translateX(100px); }
            

          

        

        
You can also use several percentages, such as 0%, 100%, to apply the same
          styles at both ends.

Useful CSS Functions & Selectors
calc, min, max, clamp, var, repeat,
              minmax + every selector type at a glance
          

        

        
A quick-reference chapter: the functions you can use inside almost any value, and the full
          selector family from basic combinator to modern :has().


        

          
💡 In simple words

          
Functions are calculators written inside CSS - clamp(18px, 4vw, 40px)
            means "grow with the screen, but never below 18px or above 40px". Selectors are the
            address system: every property needs a selector to say who receives it.
          

        


        

          

            

              Function
              Example
              What it does
            

            

              calc()
              width: calc(100% - 40px);
              Math with mixed units (%, px, em) - one free space rule; keep spaces around + and -
            

            

              min()
              width: min(600px, 90%);
              Picks the smallest of the options - a max-width that also respects small screens
            

            

              max()
              font-size: max(16px, 2vw);
              Picks the largest - a floor that grows on big screens
            

            

              clamp(min, preferred, max)
              font-size: clamp(18px, 4vw, 40px);
              Fluid sizing: preferred value scales between a hard min and max (responsive typography)
            

            

              var(--name) / var(--name, fallback)
              color: var(--primary);
              Reads a custom property (variable); fallback used when undefined
            

            

              repeat()
              grid-template-columns: repeat(4, 1fr);
              Repeats a track pattern; supports auto-fill/auto-fit keywords
            

            

              minmax()
              minmax(220px, 1fr)
              Sets min and max for a grid track - responsive card rows without media queries
            

            

              rgb() / rgba() / hsl() / hsla()
              rgb(37 99 235 / .8)
              Color functions with alpha channel support (modern space-separated syntax)
            

            

              url()
              background: url("img.png");
              Points to a file (image, font, SVG)
            

            

              attr()
              content: attr(data-tip);
              Reads an HTML attribute into CSS content (tooltips with ::after)
            

            

              counter() / counters()
              content: counters(item, ".");
              Auto-numbered lists/sections with counters
            

            

              translate() / scale() / rotate() …
              transform: translate(-50%, -50%);
              Transform functions (Transforms lesson) - math done at paint time, no layout change
            

            

              linear-gradient() / radial-gradient()
              background: linear-gradient(#06b6d4, #3b82f6);
              Generates gradient images inline (Backgrounds lesson)
            

          

        


        

          

            

              Selector type
              Example
              Matches
            

            

              Grouping
              h1, h2, h3
              Every listed selector at once (comma = "or")
            

            

              Descendant combinator
              .nav a
              Any <a> anywhere inside .nav (any depth)
            

            

              Child combinator
              .nav > a
              Only direct children of .nav
            

            

              Adjacent sibling
              h2 + p
              The element immediately after h2
            

            

              General sibling
              h2 ~ p
              Every p after h2 at the same level
            

            

              Attribute variants
              [href], [href="x"], [href^="https"],
                [href$=".pdf"], [class*="btn"], [rel~="tag"],
                [lang|="en"]
              
              has / equals / starts-with / ends-with / contains / contains word / hyphen-prefix
            

            

              :not()
              li:not(.active)
              Everything except that selector (can take a list)
            

            

              :is()
              :is(h1, h2, h3) { }
              Any of the listed selectors without specificity cost of the longest one
            

            

              :where()
              :where(.card) p
              Same as :is() but always zero specificity - perfect for base styles you want overridable
            

            

              :has()
              label:has(input:checked)
              The "parent selector" - matches parents that contain a matching element (newer; check support
                and use progressively)
            

            

              Pseudo-classes
              :hover, :focus-visible, :nth-child(2n),
                :checked
              
              State or position of an element (Pseudo lesson)
            

            

              Pseudo-elements
              ::before, ::after, ::placeholder, ::first-line
              
              Generated parts of an element (Pseudo lesson)

1What does CSS stand for?

          

            Show answer
            
Cascading Style Sheets - "cascading" because later/more specific rules
              override earlier ones.

          

        


        

          
2Which selector targets every element with
              class="btn"?

          

            Show answer
            
.btn { } - classes start with a dot. Ids use #, type selectors
              use the bare tag name.

          

        


        

          
3Inline, internal and external CSS all set a different color
              on the same element - which one wins?

          

            Show answer
            
Inline (then internal, then external) - highest specificity wins, but real
              projects avoid inline styles because they are so hard to override.

          

        


        

          
4Name the four layers of the box model, from the
              inside out.

          

            Show answer
            
content → padding → border → margin. Padding is inside the frame, margin is
              the empty space outside it.

          

        


        

          
5Why do professionals put * { box-sizing: border-box;
              } at the top of every stylesheet?

          

            Show answer
            
So width: 300px means the whole box is 300px - padding and
              border fit inside the width instead of being added on top (which breaks layouts).

          

        


        

          
6What is the difference between margin and
              padding?

          

            Show answer
            
Margin is space outside the border (between boxes) and can collapse.
              Padding is space inside the border (between border and content) and never
              collapses.
            

          

        


        

          
7How do you horizontally center a block element with a fixed
              width?

          

            Show answer
            
margin: 0 auto; - equal left/right auto margins push the box to the middle
              (it needs a width less than 100%).

          

        


        

          
8Write the three lines that perfectly center a child inside a
              parent, both horizontally and vertically.

          

            Show answer
            
display: flex; + justify-content: center; +
              align-items: center; on the parent.
            

          

        


        

          
9What do the three values in
              flex: 1 1 200px stand for?

          

            Show answer
            
grow, shrink and basis - the item grows to share free space, may shrink,
              and starts from a 200px base size.

          

        


        

          
10Which value makes an element disappear without leaving
              a gap behind?

          

            Show answer
            
display: none; - visibility: hidden also hides it but keeps
              the empty space.

          

        


        

          
11Explain what font-size: clamp(1rem, 5vw, 3rem);
              does.

          

            Show answer
            
The font scales with the screen (5vw) but never shrinks below
              1rem and never grows past 3rem - responsive type without media
              queries.
            

          

        


        

          
12Write a media query that applies styles only on screens
              600px wide or smaller.

          

            Show answer
            
@media (max-width: 600px) { … } - or mobile-first style:
              @media (min-width: 601px) { … } for everything larger instead.
            

          

        


        

          
13Three rules target one element: div { },
              .box { }, #main { }. Which one wins - and what beats them all?

          

            Show answer
            
#main (id) beats .box (class), which beats
              div (element) - specificity: id > class > element. Among normal declarations, an
              inline style="…" attribute ranks highest - but any author
              !important still beats a normal inline style.
            

          

        


        

          
14In box-shadow: 0 4px 12px 6px #000, what does
              the fourth value do? Does text-shadow accept it?

          

            Show answer
            
6px is the spread-radius - it grows the shadow around the box (blur is
              12px). text-shadow has no spread-radius and no inset - only offset-x, offset-y,
              blur-radius and color.

          

        


        

          
15What is the difference between display: none,
              visibility: hidden and opacity: 0?

          

            Show answer
            
display: none - no box at all, space removed.
              visibility: hidden - empty space stays, not clickable.
              opacity: 0 - invisible but space stays and it can still be clicked (great for
              fade animations, wrong for hiding content).
            

          

        


        

          
16You have a 180×120px box and a photo of any size. Which two
              properties crop it neatly to fill the box?

          

            Show answer
            
object-fit: cover; fills the box and crops the overflow; add
              object-position: center top; if you must keep the top (faces, logos) visible.
            

          

        


        

          
17Why do we use outline for keyboard focus
              instead of border?

          

            Show answer
            
Outline is drawn outside the box and takes no space - so nothing on the page
              jumps when it appears. A border would resize the element. Add outline-offset
              for a small gap, and use :focus-visible so mouse users don't see it on
              every click.

          

        


        

          
18True or false: "an absolutely positioned element is always
              glued to its nearest positioned ancestor."

          

            Show answer
            
Usually, but not always. It is glued to its containing block - which is the
              nearest ancestor with a positioning (relative/absolute/fixed/sticky) or one with
              transform, filter,
              perspective or contain. With no such
              ancestor, it aims at the page itself.
